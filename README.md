# StudentCBSEScience10Hub

An original, navigable study handbook for CBSE Class 10 Science (086), academic year 2026–27.

**Read the handbook online:** https://nareshgrampalli-coder.github.io/StudentCBSEScience10Hub/

The site is built with Jekyll and published through GitHub Pages. The online contents page links to the examination overview, five unit guides, 13 chapter pages, and final revision materials. Navigation labels and page order are maintained in `_data/book.yml`.

The deployment workflow is in `.github/workflows/pages.yml`. GitHub Pages must first be enabled for this repository: open [Settings → Pages](https://github.com/nareshgrampalli-coder/StudentCBSEScience10Hub/settings/pages) and set **Build and deployment → Source** to **GitHub Actions**. The first workflow run returned 404 because no Pages site was enabled; the site links above will work after Pages is enabled and a deployment succeeds.
