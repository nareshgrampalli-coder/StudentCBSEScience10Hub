# StudentCBSEScience10Hub

An original, navigable study handbook for CBSE Class 10 Science (086), academic year 2026–27.

**Read the handbook online:** https://nareshgrampalli-coder.github.io/StudentCBSEScience10Hub/

The site is built with Jekyll and published through GitHub Pages. Content is organized in `handbook/`; navigation labels and page order are maintained in `_data/book.yml`.

The handbook is an independent study resource, not a CBSE publication. Check the [official CBSE curriculum](https://cbseacademic.nic.in/curriculum_2027.html) and school instructions for current syllabus and assessment requirements.
